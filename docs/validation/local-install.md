1. 原生目录选择器选取最小 MV3 测试产物，应用预览名称与版本。
2. 输入“Chrome 隔离测试配置”，确认安装；应用生成固定目录并显示“待加载 / 待验证”。
3. 在 Chrome 的普通“加载未打包的扩展程序”界面加载应用生成的目录；浏览器显示版本 `1.0.0`，ID `ochangelmjhjpkjiljoioncajgcdkckf`。
4. 在应用填写该 ID，但输入版本 `9.0.0`：提示不一致，记录仍为待验证；改为实际 `1.0.0` 后显示“用户已确认”。
5. 关闭应用窗口，进程正常退出；重新启动后同一安装仍显示“用户已确认”。
6. 保留旧 ID/版本输入，再安装第二个同版本副本：新安装记录待验证，两个确认输入均清空，旧确认未带入新记录。
