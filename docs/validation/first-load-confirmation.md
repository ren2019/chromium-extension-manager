## 核心验证

已批准测试入口仍为 `Manager` 公开用例及真实临时目录。新增用例先因缺少接口失败，再实现后通过：

- `confirm_manual` 接受明确目标、部署代数及版本；无 ID 的人工确认可重开恢复，等待浏览器识别与已确认版本同时保留。
- `installation_path` 返回本安装完整绝对路径，验证包含空格和中文、不指向来源目录；过期部署和错误配置不能取得另一安装的交接路径。
- 错误目标、旧代数和版本不符的确认不修改安装记录；一个配置的确认不影响另一配置。
- 安装和文件更新时间不会被确认改写。既有已知 ID 仍保留，旧 `confirm` 兼容入口仍受原身份检查保护。
