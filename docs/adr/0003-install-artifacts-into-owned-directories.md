# 从可加载产物安装到独立固定目录

首版接收公开及私有 GitHub Release ZIP、仓库指定引用和子目录中的可加载产物，以及本地目录；GitHub 目录读取记录解析后的具体提交，不执行来源仓库的构建脚本。与只支持 Release ZIP 相比，这覆盖直接从仓库分发成品的扩展；与自动构建源码相比，避免要求普通用户配置构建环境，也不将来源脚本执行引入安装流程。

本地来源以扩展根目录的 `manifest.json.version` 声明版本，文件复制到管理器固定安装目录，不让浏览器直接依赖用户的来源目录。这样来源移动或变更不直接改变已安装扩展；同版本内容变化需要用户明确选择重新部署。
