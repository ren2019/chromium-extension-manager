# 扩展安装必须独立于管理器持续可用

本产品优先服务用户的日常浏览器，用户已确认安装后的扩展必须在管理器退出、浏览器正常重启后继续可用。因此，安装方案必须支持持久安装，不以管理器常驻或每次浏览器启动时重新注入扩展作为可用性的前提；必要时接受首次手动加载。

这使“首次全自动加载”服从于“安装后独立可用”。调试协议的临时加载只能作为辅助能力，其返回安装成功不能单独证明满足本产品的安装验收；应在管理器退出和浏览器重启后验证扩展身份、配置及运行状态。

Chromium 已提交[下次启动时卸载通过 CDP 安装的扩展](https://github.com/chromium/chromium/commit/03338921851f5a0773c4d6b68586133851e2ca4e)的实现，说明此区别有实际影响。目标 Chrome/Edge 在 Windows/macOS 上的行为仍需实测，不将主干代码视为所有发行版本的保证。
