# CEPM · OpenLogi 浅色交互样稿

**Throwaway UI prototype / 非生产代码。视觉待用户确认。**

问题：保留已批准 A 的操作结构、采用 OpenLogi 浅色组件语言后，用户是否觉得界面更清楚、安静、易用？本轮仅制作已选定的一种方向，不重新加入 A/B/C 选择。

规格：[Issue #10](https://github.com/ren2019/chromium-extension-manager/issues/10)。`SPEC.md` 是制作时的规格快照，后续以 Issue 的用户决定为准。

## 打开

直接双击 `index.html` 即可，无依赖、无需构建。全部图标内嵌，页面运行无需外部网络。

也可在仓库根目录运行：

```sh
python3 -m http.server 4319 --bind 127.0.0.1 --directory prototypes/visual-refresh
```

然后打开 `http://127.0.0.1:4319/?scene=daily`。

应用画框为 **1120×780**。浏览器工具栏占空间时可全屏预览；只验收这个正常应用尺寸。底部“场景”工具条是演示控件，不属于产品。

## 建议查看顺序

1. 日常首页：点击“检查更新”查看新版本标记；列表同时显示安装与最后更新时间。点击扩展行进入右侧完整详情，所有信息默认展开，操作集中在顶部。
2. 左上角 Profile：置顶/取消置顶、切换 Chrome/Edge；置顶不改变当前选择，列表限定当前配置。
3. “添加扩展”：选择来源、确认安装两步；在预览中切换版本；安装后查看首次加载说明并记录 ID。
4. “等待加载 / 重载”场景：OpenCLI 演示一次更新结果提醒，页面笔记演示首次加载。首次 ID 演示值可使用 `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa`。
5. 空列表、检查失败、本地修改冲突、配置不可用场景。错误重试使用可控成功响应。

## 样稿范围与演示边界

- 正常、发现新版本、空列表、等待加载/重载、检查失败、本地冲突、目标缺失、各配置版本及更新失败处理九类场景。`?scene=updates` 可直接查看发现新版本的列表。
- 包含详情、其他版本、恢复、原生管理交接的辅助样式；三种来源输入均可演示。
- 所有安装、获取、部署、确认及配置定位都是内存演示，不访问真实来源，不读取浏览器配置，不操作真实扩展，不执行命令或写安装目录。
- 只有样稿自己的置顶列表和最后配置保存在 `cepm-visual-prototype-preferences-v1`。安装和记录刷新后重置；选定异常场景会回到对应的演示配置，日常场景恢复最后选择。
- 左侧浏览器管理、复制目录和打开目录仅显示演示反馈；关于页的项目与反馈链接为真实公开网址。
- 阅读助手、页面笔记、版本变更和错误均为示例，不声称是实际安装或真实新版本。OpenCLI 图标与 1.0.26 名称/版本来自此前验收的公开扩展产物。
- 样稿不覆盖真正的下载、文件选择、版本枚举、多个附件/根目录歧义及批量执行。生产实现仍须按完整规格覆盖这些现有流程。
- 不将原型直接并入生产。样稿确认后由 GPUI 实现，真实应用另行验收。

## Edge 优先与按需连接（2026-10-30）

问题：在真实能力边界内，如何让 APP 承担卸载和版本核对，并只在任务需要时请求连接？沿用已选视觉，不增加新的布局方案。

- `?scene=edge-connect`：Edge 按需连接；从卸载或安装处请求连接，可拒绝并手动继续。
- `?scene=edge-connected`：单次确认卸载；更新后 APP 读取版本，省去手动 ID 与版本确认；成功结束连接。
- `?scene=edge-mismatch`：更新后点击检查，浏览器仍报告旧版本，保留待处理和历史确认。
- `?scene=edge-uninstall-error`：请求卸载失败，保留当前记录并提供重试、手动移除。
- 以上均为内存演示；不发起任何真实 CDP 请求。连接能力与元数据读回是未来实现的设计依据，不代表生产 CEPM 已实现。
- 首次加载仍采用持久安装路径；没有将 CDP 临时加载包装成持久安装。更新目前保留一次浏览器重载动作。
- 连接任务完成/取消或切换目标即断开；浏览器调试开关独立，不声称重启会自动关闭。
- 实测 Edge 156 的能力及边界见 [验证报告](../../docs/validation/edge-cdp.md)。独立实验脚本 `node prototypes/visual-refresh/probes/edge-cdp.mjs` 可重现加载、重启丢失及卸载；不要与 HTML 演示混淆。
- UI 已手动检查一次确认卸载后清空当前 Edge 列表并断开连接、自动核对后版本从 1.0.26 变为 1.0.27 且确认方式为浏览器已核对、版本不匹配保持历史值、卸载失败显示重试/手动入口。JS 语法与 diff 检查通过；尚未进行生产 GUI 验收。
