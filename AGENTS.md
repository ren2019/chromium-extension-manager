# Project guidance

Read `prd-chromium-extension-package-manager.md` before planning or implementing product behavior; it is the initial requirements baseline.

## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues for `ren2019/chromium-extension-manager`. Before creating, reading, or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before classifying issues or changing triage state, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase or proposing domain terms or architectural decisions, read `docs/agents/domain.md`.
